Blood Bowl Card Creator

Create, save and print your Blood Bowl cards.

The editor runs in your browser.

About official presets

Some presets reproduce data from official publications.

Create and edit a card

  1. Choose an editor in the navigation bar.
  2. Fill in the fields or load a preset.
  3. Save a PNG or a JSON file.
  4. Reload the JSON file later to continue editing.

Print nine cards on an A4 sheet

  1. Send cards to the print workspace.
  2. Arrange up to nine cards per page.
  3. Choose cut marks, bleed, dashed borders or square corners.
  4. Print at A4 and 100% scale.
Prepare a print sheet

Professional printing

You can also send the exported cards to a professional printer.

  • Ask for a finished card size of 63 × 88 mm.
  • Enable bleed when the printer requests it.
  • Only add crop marks when requested by the printer.
  • Order a proof before a large print run.

These settings were used by the Noxoffa version. The project is not affiliated with this company.

  • MakePlayingCards — Custom Game Cards (63 × 88 mm) Playing Cards
  • 2.48″ × 3.46″ (63 × 88 mm), 55 cards
  • Card Stock: (S33) Superior Smooth
  • Finishing: MPC Game Card Finish
Historical GIMP method

This method remains available for manually composing a page.

  1. Install GIMP.
  2. Open the A4 XCF template.
  3. Add PNG files as layers and place them in the nine slots.
  4. Set margins to 0 and print at 100%.
